## Template 5: Codex Build Task

```text
Repo: [repo]
Objective: [feature/fix/refactor/test/docs]
Constraints: [stack, files, style, review rules]

Codex Prompt:
Inspect the repository, identify the minimal stable implementation path, make the smallest useful change, add or update tests where appropriate, and return a concise summary of changed files, tradeoffs, and next steps.

Acceptance Criteria:
- Builds or explains blocker
- Tests added or justified
- Minimal scope
- Clear summary
- No unrelated changes
```

## Template 6: Claude Code Task

```text
Project path: [path]
Mode: [plan/edit/review/test]

Prompt:
Analyze the project structure, produce a short plan, then implement only the requested change. Preserve existing style. Use clear error handling. Summarize files changed and recommend the next verification command.

CLI Shape:
claude -p "[task]" --max-turns 5
```
