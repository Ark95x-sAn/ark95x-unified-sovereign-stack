## Unified Tech Stack

- **Runtime**: Python 3.11 + Node.js + TypeScript
- **Orchestration**: CrewAI, AutoGen, LangGraph, n8n
- **AI Models**: Ollama, OpenAI, DeepSeek, Llama3, Mistral, CodeLlama
- **Vector Store**: Qdrant, LanceDB
- **Cache/Queue**: Redis
- **Database**: PostgreSQL, MongoDB
- **Infrastructure**: Docker, Kubernetes, Terraform
- **Search**: SearXNG, Browserbase, Stagehand
- **Frontend**: Next.js, FastAPI dashboards
- **Automation**: n8n, PowerShell, GitHub Actions
- **Trading**: OpenEvolve, MAP-Elites
